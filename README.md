# Magic 8 Ball

A decision helper with a memory. Open `index.html` in any browser — no install needed.

- **Ask**: pick a tag (Snack, Talk to strangers, …) or type a question, choose how you feel, tap the ball.
- **Memory**: every question is saved with the date, the ball's answer, and your feeling. Mark whether you did it and add notes. Stats show how often you follow the ball.
- **Settings**: rename the ball, edit/add/remove decision tags and answers, export/import a backup.

Data is stored locally in your browser (localStorage). Use *Export backup* to keep a copy.
